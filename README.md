# muttul game 부스 묶음

세명컴퓨터고등학교 게임소프트웨어과 **GAME 체험부스** 용 오프라인 버전입니다.
인터넷 없이 **공유기 + 노트북**만으로 학생들이 멀티플레이 게임을 체험합니다(게임 29종).

> 이 저장소에는 **완성된 묶음만** 올라옵니다(소스 코드·운영 서버 설정은 없습니다).
> 묶음은 [Releases](https://github.com/muttul58-coder/muttul-booth/releases/latest) 에 있습니다.

## 서버 노트북에서 받기 (인터넷이 되는 곳에서)

1. **`업데이트.bat`** 을 받는다 → [여기를 누르면 바로 받아집니다](https://github.com/muttul58-coder/muttul-booth/raw/main/%EC%97%85%EB%8D%B0%EC%9D%B4%ED%8A%B8.bat) (또는 파일 목록에서 열고 오른쪽 위 **「Download raw file」(⬇)**).
   - 브라우저가 경고하면 「유지」. 받은 파일 우클릭 → 속성 → **「차단 해제」** 에 체크.
2. `업데이트.bat` 을 **더블클릭**한다. 자동으로 최신 묶음을 내려받아 `C:\muttul-booth` 에 풀어 준다(약 80MB · 몇 분).
3. 다음부터는 같은 파일을 다시 더블클릭하면 **바뀐 게 있을 때만** 새로 받는다(이미 최신이면 바로 끝).
4. `C:\muttul-booth\부스시작.bat` 을 더블클릭 → 방화벽 창에서 「예」 → QR 안내 화면이 열린다.

⚠️ 업데이트는 **인터넷이 되는 곳(집·학교)에서 미리** 한다. 부스 현장에서는 인터넷 없이 그대로 쓴다.
⚠️ 서버 노트북은 **Windows 64비트**여야 한다. Node·git 설치는 필요 없다.
⚠️ 업데이트하면 이전 폴더는 `C:\muttul-booth.old` 로 남는다(순위 등 기록은 새로 시작한다).
